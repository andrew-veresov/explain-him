Sequence of actions

How it works

Who does what

  1. 01Originator

    Publishes the idea page, sources, and explanation rules in the repository.

  2. 02User

    Opens the explanation or gives the repository link to their personal agent.

  3. 03AIAgent

    Reads the page first, checks repository materials only when more context is needed.

  4. 04AIAgent

    Answers the user in the agent interface.

  5. 05AIAgent + Explain Him

    Uses Explain Him tools only to focus, highlight, or locally adapt the visual explanation.
