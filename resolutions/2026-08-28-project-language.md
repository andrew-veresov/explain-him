# English project language

## Decision

The public `andrew-veresov/explain-him` repository uses **English as its project language**.

This applies to repository-authored documentation, UI copy, manifests, templates, resolutions, examples, code-facing text, tests, and repository Issues prepared by agents. The deterministic public-demo check rejects Cyrillic content in project text files to prevent accidental language drift.

The rule does not constrain the end-user conversation language. A user's personal agent may explain Explain Him in the user's preferred language while keeping repository artifacts in English.
