# User and Consumer terminology

Status: accepted

## Decision

`User` and `Consumer` refer to the same participant in Explain Him. `User` is the preferred term in user-facing explanations and visual UI. `Consumer` may remain in capability-architecture material where that term describes the consumer-local execution boundary.

## Personalized correction

When a user asks about a visible User/Consumer inconsistency, the personal agent answers that they are one role and, when Site Tools are available, replaces every affected visible semantic target in the Personalized view with a typed representation using `User`. This local correction does not alter canonical authored material.
